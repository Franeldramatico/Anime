## 🌟 Sobre el Proyecto

Este proyecto es una aplicación web interactiva diseñada como un regalo de cumpleaños. Utiliza la estética y los personajes del anime **Given** para contar una historia personal y expresar sentimientos. Cada sección está dedicada a un personaje de la serie, vinculando sus personalidades y roles con mensajes especiales.

## 🚀 Tecnologías Utilizadas

- **React 19**: Biblioteca principal para la interfaz de usuario.
- **Vite**: Herramienta de construcción ultra rápida.
- **Tailwind CSS**: Para un diseño moderno, responsivo y elegante.
- **Framer Motion**: Para animaciones cinemáticas y efectos de parallax suaves.
- **Lucide React**: Set de iconos minimalistas.

## 🛠️ Instalación y Configuración

Para ejecutar este proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Franeldramatico/Anime.git
   cd GivenHonor
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Configurar variables de entorno:**
   Crea un archivo `.env` en la raíz del proyecto y añade tu clave de API (opcional para funciones de IA):
   ```env
   VITE_GEMINI_API_KEY="TU_API_KEY_AQUI"
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

## 🎨 Características

- **Diseño Cinemático**: Inspirado en la paleta de colores y el sentimiento de *Given*.
- **Efectos Parallax**: Las imágenes y textos se mueven a diferentes velocidades al hacer scroll.
- **Interfaz "Glassmorphism"**: Paneles translúcidos que dan una sensación premium.
- **Totalmente Responsivo**: Adaptado para verse bien en cualquier dispositivo.
